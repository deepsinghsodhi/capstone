In this project, we extract amino acid data from published papers provided by our stakeholder, Agriculture Canada. 
The project primarily focuses on analyzing protein quality and digestibility using metrics such as Amino Acid Score (AAS), 
Protein Digestibility-Corrected Amino Acid Score (PDCAAS), and In Vitro PDCAAS (IV-PDCAAS). Key tasks include extracting 
data from scientific papers—such as amino acid profiles, protein content, manuscript titles, and DOIs—and calculating AAS
using reference patterns. Additionally, the project combines digestibility data to compute PDCAAS/IV-PDCAAS and evaluates
regulatory compliance for protein labeling based on corrected protein content thresholds. Outputs include structured 
spreadsheets summarizing extracted data, calculations, and labeling assessments. Templates and reference patterns are
provided, adhering to FAO/WHO guidelines.
